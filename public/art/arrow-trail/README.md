# 矢印の軌跡（飛行モデル版）仕様書

- 試作リンク：https://takedatakumi.github.io/toy-box/art/arrow-trail/

## 概要と目的

エースコンバットのリザルト画面にある「矢印で描いた機体の軌跡」を、ブラウザで眺めて楽しむ3Dアニメーションとして再現し、ミサイル戦まで広げたものです。

矢印の機体が飛び回り、後ろに帯状の軌跡を引きます。モードを切り替えると、攻撃側が標的を追ってミサイルを一斉射する「追撃戦」と、2チームが互いに攻撃し合う「交戦」を眺められます。1つのHTMLファイルで動き、Three.js（r128）で描画します。保存されるデータはありません。

飛行モデル版（[矢印の軌跡](./)）の仕様を書いています。機体座標系の飛行モデル、スロットル、交戦モード、耐久力と撃墜、補充、真上カメラを備えます。

## 画面構成と操作

画面は、全面の3D表示と、右下の設定パネルで構成します。モードは3つ、視点は2つあり、追従カメラは独立したスイッチです。

**モード**

1. 軌跡だけを眺める: 機体が自由に飛ぶ。ときどき宙返りなどを見せる（初期値）
2. 追撃戦（ミサイルと回避）: 攻撃側が標的を追い、標的は回避する
3. 交戦（互いに攻撃）: 2チームが互いに攻撃し、回避する

**視点と追従カメラ**

- 視点は「斜め」と「真上」。切り替えるとカメラがなめらかに移る。真上でも、ドラッグで画面を回せる
- 追従カメラは、追撃戦と交戦で使えるチェックボックス。詳細は「追従カメラの仕様」を参照

**画面の表示**

- 左上: タイトルと操作のヒント。追従カメラがオンのときは、追っている機体の耐久力
- 右上: 撃墜数（交戦のみ）
- 右下: 設定パネル。「設定」ボタンで開閉する。広い画面では初期で開き、狭い画面では閉じる

**カメラ操作**

- ドラッグで回転、ホイールとピンチで拡大縮小（距離80〜520）
- 真上では、左右のドラッグで画面を回す。上下のドラッグは無効
- 「カメラを自動で回す」は初期でオン。OSの「視差効果を減らす」設定では、初期でオフ
- 「最初から」で配置を作り直し、「一時停止」で動きを止める（カメラ操作は可能）

## 飛行モデル

機体の姿勢をクォータニオンで持ち、ロール・ピッチ・ヨーの角速度を機体の軸で積分します。旋回は「機体を傾けて機首を引く」ことで生まれ、進行方向は常に機首の向きです。

**姿勢と操縦**

- 軸は、機首が+Z、右翼が+X、上が+Y
- 角速度には上限があり、応答に遅れがある（ロール約7/秒、ピッチ約5/秒、ヨー約4/秒の追従）
- ピッチの上限は「許容G × 重力 ÷ 速度」（最大2.4rad/秒）。速度が約8〜20のときは、舵が効きにくい
- パイロットは、進みたい方向を機体座標で見て、誤差が大きければ傾けて引く。目標が揚力の反対側にあるときは、軽く押し下げる。誤差が小さければ翼を水平に保ち、方向舵で微調整する

**スロットルと速度**

- 加速度 = 推力 − 空気抵抗 − 旋回の負荷による抵抗 − 重力の機首方向成分
- 推力は、スロットル（0〜1、アフターバーナーは1.3）× 18。空気抵抗は 0.01 × 速度²。旋回の負荷は、荷重倍率 n に対して 0.12 × (n² − 1)。重力は12
- 上昇すると減速し、降下すると加速し、急旋回で速度が落ちる。速度の範囲は9〜75
- 巡航中は、目標速度（個体ごとに約25〜35）をオートスロットルで保つ

**通常飛行**

- ゆるやかに進路を変え、地面から約18〜62の高さ（最大85）を保つ
- 14〜28秒ごとに、見せ場の機動を行う。宙返り、インメルマンターン、バレルロールで、範囲の中心寄り（半径の約0.6倍以内）でだけ始める。宙返りの前には、速度36まで加速する

**安全処理（最優先）**

- 地面や前方の地形に近づくと、引き起こす
- 飛行範囲（半径125）の約0.6倍を超えると、中心へ戻る向きに寄せる。1.2倍を超える、または高さが135を超えると、機動を打ち切って戻る
- 高さが100を超えると降下する。速度が17未満になると、機動をやめて加速し、機首を下げる

**1ステップの流れ**

1. 状況から、進みたい方向、操縦の限界、スロットルを決める
2. 進みたい方向から、ロール・ピッチ・ヨーの指令を作る
3. 指令を、上限と遅れのある角速度にする
4. 姿勢を更新し、速度と位置を進める

## 機体と軌跡の表現

機体は平たい矢印で、軌跡は翼端を結ぶ帯です。帯はロールに合わせてねじれるので、回転の履歴が軌跡に残ります。

**矢印**

- 平たいダーツ形（長さ約3.6、翼幅3.0に、大きさの倍率を掛ける。初期は×1.5）。半透明の塗りと、明るい縁取り
- 機体の向き（ロール・ピッチ・ヨー）に合わせて表示する
- 被弾すると、白く光る
- 機体から地面へ、細い線を引く（高さの目安）

**軌跡（帯）**

- 左右の翼端を結ぶ帯。帯の幅は、矢印の大きさに連動する
- 古い部分ほど薄く、先頭は透明から始まって、約6単位かけて濃くなる（矢印と重ならないため）
- 長さは50〜1500点（初期450）。加算合成で描く
- 撃墜された機体の軌跡は、約2.2秒かけて薄れる

**地形と背景**

- 地形は、ワイヤーフレーム。高いほど明るく、中心から離れるほど薄い。表示は切り替えられる
- 霧は、カメラの距離に連動する。遠くの機体は、霧の中から姿を現す
- 背景は、暗い紺色

**色**

| モード | 色 |
| --- | --- |
| 軌跡だけ | 水色、氷色、水色、琥珀を、機体の順に繰り返す |
| 追撃戦 | 攻撃側は水色。逃げる側は氷色と琥珀を交互 |
| 交戦 | チームAは水色系、チームBは琥珀系 |

## 追撃戦モード

攻撃側が標的を追ってミサイルを一斉射し、逃げる側（標的）が回避します。攻撃側は被弾しません。

**構成**

- 攻撃側と逃げる側の数を、別々のスライダーで指定する（各0〜16、初期は4と4）
- 最初は、標的が中央寄りに散らばり、攻撃側は、どれかの標的の後方80〜110に付く

**攻撃側**

- いちばん近い標的を狙う。0.3秒ごとに見直し、明らかに近い標的が現れたときだけ切り替える（距離の比が約1.22倍以上）
- 標的を先読みして追う。距離が32未満（機銃がオンなら20未満）になると、機首を上げて距離を取る。距離が100を超えると、アフターバーナーで追う
- ミサイルを撃つ条件は、距離が35〜170で、機首と目標のなす角が0.5rad未満で、機動中でないこと
- 一斉射の数は設定（初期9発）。発射の間隔は0.04秒で、次の一斉射まで5〜8秒空ける

**逃げる側**

- 自分に向かうミサイルが距離95未満に近づくと、回避機動に入る。ブレイクターン、切り返し、バレルロール、スプリットSから、ランダムに選ぶ。ロール系が続かないように、間を空ける
- ミサイルが距離100未満に近づくと、フレアを6発撒く。発射の間隔は0.09秒で、次の使用まで2.2秒空ける
- 回避機動の間は、スロットルを絞る（減速して相手に追い越させる）か、アフターバーナーを使う

## 交戦モード

2チームが向かい合って戦い、全機が「攻撃」と「回避」の両方を行います。ミサイルは敵だけを狙い、味方には当たりません。

**構成**

- チームAとチームBの数を、別々のスライダーで指定する（各0〜16、初期は4と4）
- 最初の配置は、チームAが左側（東向き）、チームBが右側（西向き）で、向かい合って飛ぶ
- 色は、チームAが水色系、チームBが琥珀系

**全機の動き**

- いちばん近い敵を追い、攻撃の条件が揃えばミサイルを一斉射する（条件は追撃戦の攻撃側と同じ）
- 自分に向かうミサイルが近づくと、回避を最優先する。回避機動とフレアは、追撃戦の逃げる側と同じ
- 全機に耐久力がある。耐久力と撃墜は「ミサイル・機銃・耐久力・撃墜」を参照

**スコア**

- 右上に「チームA　n : n　チームB」の形で、撃墜数を表示する
- 撃墜数は、撃墜したミサイル（または機銃）を撃った側のチームに加算される
- 「最初から」やモードの切り替えで、0に戻る

## ミサイル・機銃・耐久力・撃墜

ミサイルにはエネルギーがあり、旋回すると速度が落ちます。標的の回避機動やスロットル操作が効くので、ミサイルが標的の近くで爆発する割合は、発射数の約1〜2割です（模擬実行での値）。

**ミサイル**

- 一斉射では、機首から約30〜70°の扇状にばらけて発射する。初速は、発射した機体の0.9倍（最低28）
- 推進剤の燃焼時間は2.0〜2.8秒で、その間は加速する。燃え尽きたあとは、空気抵抗（0.004 × 速度²）と、旋回による負荷で減速する
- 旋回できる角速度は、「最大旋回G（9〜12）× 重力 ÷ 速度」で決まる。速度が高いほど、曲がれない
- 標的への視線に、減衰する回転成分を足して、大きならせんを描く（板野サーカス風の軌道）。地面すれすれでは、機首を上げる
- 近接信管の距離は、標的が3.5、フレアが4。フレアには約80%が惑わされる（1回だけ）。標的が消えたら、別の標的を狙い直す
- 寿命は6〜8秒。推進剤が切れて0.5秒後に、速度が20未満になると自爆する。地面にも爆発する
- 白い煙の軌跡を引き、消えるまで約2.2秒かけて薄れる

**機銃**

設定パネルの「機銃」チェックボックスで切り替える（初期はオン）。数値は、コードの定数から転記しています。

- 射程110、最短距離22。機首と目標のなす角が約8°（0.14rad）未満のときに撃ち始める
- 連射の間隔は約0.055秒（約18発/秒）。1回の連射は1.2〜2.4秒で、次まで1.0〜2.5秒空ける
- 1発のダメージは0.05（約20発で、ミサイル1発分）

**耐久力と撃墜**

- 「耐久力（被弾に耐える回数）」は1〜10で、初期は4。ミサイルの命中は1、機銃の1発は0.05を引く
- 被弾できるのは、追撃戦では逃げる側だけ、交戦では全機
- 耐久力が0になると撃墜される。大きな爆発とともに矢印が消え、軌跡は別枠で約2.2秒薄れる
- スライダーを動かすと、生きている機体の耐久力は、残りの割合を保って換算される

**爆発**

- 閃光、火花、衝撃リングで表現する。撃墜時の爆発は、ミサイルの爆発より大きい

## 補充と飛来

撃墜された機体の分は、設定した時間が経つと、遠方から飛来する新しい機体で補われます。数は、常に保たれます。

**撃墜から補充まで**

1. 耐久力が0になると、機体が爆発して消える。軌跡は、別枠（最大24枠）に写して、約2.2秒かけて薄れさせる
2. 「補充までの時間」（0〜5秒、0.5秒刻み、初期0秒）が経つと、同じ枠に新しい機体を出す。耐久力は満タンで、軌跡も新しく始まる
3. 補充機は、範囲のはるか外（中心から約600、高さ50〜90）に現れ、戦場の中心付近へ向けて、速度70で直進する
4. 中心から半径の約0.95倍に入ると、到着したとして、通常の機体に変わる（到着まで約7秒）

**飛来中の扱い**

- 敵に狙われず、ミサイルの標的にならない。カメラの追従の対象にもならない
- 霧の中から、小さな点として姿を現す
- 出現する方向は、交戦では自陣側（チームAは左側、チームBは右側）、追撃戦ではランダム

**数のスライダーを増やしたとき**

- 追撃戦と交戦では、増えた機体も、遠方から飛来して加わる
- 軌跡だけを眺めるモードでは、増えた機体は、その場に散らばって現れる

## 追従カメラの仕様

追従カメラは、追う機体を常に画面の中心にとらえます。追撃戦と交戦でだけ使え、追っていた機体が撃墜されると、カメラはその場で停止します。

**基本**

- 「追従カメラ」をオンにすると、カメラの距離が140になる。オフにすると、元の距離と位置に戻る
- カメラの注視点が、追う機体をなめらかに追う。ドラッグでの回転と拡大縮小は、追従中も使える

**追う機体の選び方**

- 追従するチームを選べる。交戦は「チームA／チームB／両方」（初期は両方）、追撃戦は「攻撃側／逃げる側／両方」（初期は逃げる側）。モードを変えると、そのモードの初期値に戻る
- 追える機体の条件は、生きていて、飛来中でなく、選んだチームに属すること
- 「次の機体」ボタンで、選んだチームの機体を、枠の順に切り替える
- チームの選択を変えると、追っている機体が選んだチームでなければ、そのチームのいちばん近い機体へ、すぐ切り替わる。追える機体がいないときは、現れるまでカメラが待つ

**撃墜されたとき**

- 追っていた機体が撃墜されると、カメラはその場で停止する。補充機が同じ枠に出ても、自動では移らない
- 「撃墜されたら自動で次の機体へ」をオンにすると（初期はオフ）、撃墜位置にいちばん近い、追える機体へ自動で切り替わる

**表示（左上）**

- 「追従中: チームA 3番機　耐久力 2 / 4」の形で、機体と耐久力を表示し、耐久力のバーを添える。25%以下では、バーが琥珀色になる
- 撃墜後は「撃墜されました（「次の機体」で切り替え）」、追える機体がないときは「追える機体がありません」と表示する
- 追撃戦で攻撃側を追うときは、被弾しないので、耐久力は表示しない

## 検証状況・制限・保留事項・決定の経緯

動作は、描画を除く模擬実行（ヘッドレス）で確認しました。実際の見た目と描画の負荷は、ブラウザでの確認が必要です。

**検証した内容（模擬実行）**

- 通常飛行（120秒分）で、地面への接近や不正な値は出なかった
- 追撃戦のミサイルが、標的の近くで爆発する割合は、発射数の約1〜2割
- 交戦4対4（耐久力4）の120秒間で、撃墜は約14〜25回。補充機の到着は平均6.9秒。チームAは左側、チームBは右側から出現した
- 16対16では、同時に飛ぶミサイルが最大約100発
- 補充までの時間を0秒と3秒にして、設定どおりに補充され、撃墜された軌跡が途中で消えないことを確認した
- 追従カメラの停止、次の機体、自動切り替え、チーム固定は、すべて動作した

**既知の制限**

- 追撃戦と交戦では、機体が地形の範囲（約±160）の外へ出ることがある（時間の数%）。ごく稀に、地面すれすれまで降りる
- 宙返りなどの見せ場の機動は、範囲の中心寄りにいるときだけ始まる。頻度は多くない
- 16対16などでは、ミサイルと軌跡の線が増え、端末によっては重くなる可能性がある
- 両チームが同じ動きをするので、交戦の撃墜数の差は、運の影響が大きい

**保留中の事項**

- チームごとの戦力差（耐久力と攻撃頻度）。「耐久力と攻撃頻度を、チームごとに別々のスライダーで指定する」案を提示した段階で、方式は未決定

**決定の経緯**

| 項目 | 決定内容 |
| --- | --- |
| 軌跡の表現 | 線から、翼幅の帯へ変更。ロールを帯のねじれとして残す。矢印との重なりは、先頭のグラデーションで解消 |
| 追撃戦 | 切り替え式で追加。演出は「派手」（一斉射、フレア、爆発）。標的に回避機動を持たせる |
| ミサイルの当たりすぎ | ミサイルにエネルギーを持たせ、標的のスロットル操作と回避が効くようにした |
| 飛行モデル | 機体座標系の飛行モデルを採用した |
| 耐久力 | 逃げる側だけが被弾し、「耐久力」スライダーを付ける。0で撃墜される |
| 補充 | 範囲の縁から、遠方（約600）からの飛来へ。「補充までの時間」スライダー（初期0秒）を追加し、撃墜された軌跡は別枠で薄れさせる |
| 追従カメラ | 追撃戦の標的を追うモードから、独立したスイッチへ。撃墜後は停止し、自動切り替えはオプション（初期オフ）。追うチームを選べる |
| 交戦モード | 2チームの対戦。全機が攻撃と回避を行い、撃墜数を右上に表示する |
| 真上カメラ | 「視点」の切り替え（斜め／真上）として追加 |
| 機銃 | 別の編集で追加された機能。本書の記述は、コードの定数に基づく |
