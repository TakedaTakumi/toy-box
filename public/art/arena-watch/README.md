# アリーナ観戦 仕様書

- 試作リンク：https://takedatakumi.github.io/toy-box/art/arena-watch/

## 概要と目的

Haloの対戦モードのような3Dシューターを、操作せず眺めるだけのコンテンツとして作る第一歩です。現状は地面とキャラクターだけで、射撃・やられ・スコアはまだありません。1つのHTMLファイルで動き、Three.js（r128）で描画します。保存されるデータはありません。

## 画面構成と操作

- 地面は80×80のアリーナで、格子模様と、遮蔽物の箱が7つあります。
- キャラクターは、箱・円柱・球で組んだ人型です。バイザーと銃を持ち、腕と脚は上下2節で、肘と膝が曲がります。歩くと手足を振り、膝は後ろへ振る脚だけが曲がります。ブルーとレッドの2チーム、各3体です。
- カメラは、選んだキャラの後ろから追う三人称視点です。
- 画面のタップ、または「次のキャラ」で追うキャラを切り替えます。「自動切替」がONのときは10秒ごとに切り替わります。

## ボットの動き

- 遮蔽物を避けた地面の点を目的地に選び、向きを変えてから歩きます。到着すると少し立ち止まり、次の目的地を選びます。
- 遮蔽物とアリーナの端にはぶつからず、押し戻されます。
