# すうじモンスター

足し算・引き算を覚え始めた子ども向けの、タップだけで遊べる計算ゲームのプロトタイプです。
モンスターが出す式に合う数字の「ごはん」をタップして食べさせます。

- 形式: 単一の HTML ファイル（ビルド不要）
- 操作: タップのみ（キーボード入力なし）
- 状態: プロトタイプ（Claude で作成。実機での検証は未実施）

## 想定ユーザー

- 足し算・引き算を覚え始めた幼児〜低学年（目安: 4〜7歳）
- 画面表記はひらがな中心。数字は大きく表示し、選択肢のボタンも大きめにしている

## 遊び方

1. ホームで「難易度」「問題数」「こたえかた」を選び、「たしざん」「ひきざん」「ごちゃまぜ」のいずれかを押すと始まる
2. 吹き出しに式が出る（例: `3 ＋ 5 ＝ ？`）
3. 下の4つの数字ボタンから、正解をタップする（「こたえかた」を「テンキー」にしたときは、数字を入れて「OK」を押す）
4. 正解するとごはんがモンスターの口に飛び、ぱくっと食べる。次の問題へ進む
5. 全問終わると結果画面（星・所要時間）が出る

## 難易度

| 難易度 | 内容 | 例 |
|---|---|---|
| かんたん | 式の答えを聞く | `3 ＋ 5 ＝ ？` |
| ふつう | 式の右側の数が穴 | `3 ＋ ？ ＝ 8` / `8 － ？ ＝ 3` |
| むずかしい | 左右どちらかの数が穴（引き算の左の数も含む） | `？ ＋ 5 ＝ 8` / `？ － 3 ＝ 5` |

「むずかしい」では、同じ数の組でも穴の位置が違う式は別の問題として扱う。

## 出題仕様

### 数の範囲

| 種類 | 範囲 |
|---|---|
| たしざん | 一桁どうし（1〜9）。答えは最大 18 |
| ひきざん | 引かれる数 2〜9、引く数 1〜引かれる数。答えは 0 以上（0 になる式も出す） |
| ごちゃまぜ | 上の両方 |

### 重複しない出題

そのモード・難易度で出せる問題をすべて作ってシャッフルし、前から必要な数だけ出す。1回のプレイ中に同じ問題は出ない。
「3 ＋ 5」と「5 ＋ 3」は別の問題として数える。

### 問題数（10〜60問から選択）

| 難易度 | たしざん | ひきざん | ごちゃまぜ |
|---|---|---|---|
| かんたん・ふつう | 81 | 44 | 125 |
| むずかしい | 162 | 88 | 250 |

問題の種類が選んだ問題数より少ない組み合わせ（「かんたん」「ふつう」の「ひきざん」で 50・60 問を選んだ場合）は、出せる数までに自動で減らして始める。
このとき最初の問題で「ひきざんは 44もん だよ」と表示する。

### 選択肢

4つのボタンを表示する。正解のほかに、次のような数から3つを選ぶ。

- 正解の前後の数（±1、±2）
- 式に出てくる他の数（間違えやすい数）

範囲は 0 以上で、「かんたん」のたしざんは 18 まで、それ以外は 9 まで。ボタンの色は位置で固定で、色から正解は分からない。

## こたえかた（入力方式）

ホームの「こたえかた」で切り替える。初期値は「えらぶ」で、選んだ方式はページを開いている間だけ覚える。

| 方式 | 内容 |
|---|---|
| えらぶ | 4つの数字ボタンから正解をタップする |
| テンキー | 3×4 のキー（1〜9、下の段は「けす」「0」「OK」）で答えを入れ、「OK」で判定する |

テンキーの仕様:

- 入力した数字は、吹き出しの穴（「？」の位置）に表示する。入力は最大2桁
- 先頭が 0 のときに別の数字を押すと、0 を置き換える（「05」にはならない）
- 「OK」は入力があるときだけ押せる
- 不正解のときは入力が消え、ヒントの点が出る
- 正解のときは、答えの数字のごはんが口に飛ぶ。そのほかの演出や制限時間のゲージは「えらぶ」と同じ

## フィードバック

### 正解したとき

- 数字ボタンがモンスターの口に飛んでいき、ぱくっと食べる（効果音・星のエフェクト付き）
- 穴の「？」が緑の数字に変わり、ほめ言葉が出る

### 間違えたとき

- 押したボタンが薄くなり、選べなくなる（やり直しは何度でも可）
- モンスターが首を振り、「おしい！ もういっかい」と表示する
- ヒントの点が表示される

### ヒントの点

間違えたとき、または時間切れのときに、吹き出しの中に点を並べる。

- 分かっている数は色付きの点
- 穴の分は点線の点
- ひきざんでは、引く分を点線で表す

## 制限時間（ゆるい制限時間）

- 1問あたり 10 秒。吹き出しの上のゲージで残り時間を見せる
- 残り 3 秒でゲージがオレンジになる
- 0 になっても失敗にはならない。「おなかすいた〜！」と表示してヒントの点を自動で出し、そのまま答えられる
- 時間切れは「間違い」には数えない（星の判定に影響しない）
- 正解の演出中とホームに戻ったときはゲージを止める。別のタブを見ている間は進まない
- 「動きを減らす」設定の端末では、ゲージを1秒ごとの段階表示にする

## 計測と前回との比較

- 計測: 最初の問題が出てから、最後の問題に正解するまでの実時間（途中の演出時間を含む）
- 結果画面に「かかったじかん」を表示する
- 前回との比較: 難易度・モード・問題数・こたえかたが同じ組み合わせで、前回より速かったときだけ「まえより ○びょう はやい！」と表示する。遅かったときは何も表示しない
- 前回のタイムはメモリ上にだけ保持し、ページを閉じるか再読み込みすると消える

## 進み具合と結果

- プレイ中: 進捗バーと「3 / 20」の表示
- 結果画面: 星 1〜3 つ、所要時間、「いちどで せいかい」の数を表示する

| 一度で正解した割合 | 星 |
|---|---|
| 90% 以上 | 3つ |
| 60% 以上 | 2つ |
| それ未満 | 1つ |

## 保存するデータ

ブラウザの `localStorage` に保存するのは、次の1つだけ。

| キー | 内容 |
|---|---|
| `sm_sound` | 効果音のオン/オフ |

ごはんの累計（ホームの「このページで たべたごはん」）、選んだ難易度・問題数、前回のタイム、スコアや成績は保存しない（ページを閉じるか再読み込みすると初期値に戻る）。
保存に失敗しても（プライベートブラウズなど）、そのまま遊べる。

## 技術メモ

- 単一の HTML ファイル（HTML / CSS / JavaScript をすべて同梱）。フレームワーク・ビルド不要
- 外部リソース: Google Fonts（M PLUS Rounded 1c）のみ。読み込めない場合は端末の丸ゴシック系フォントで表示する
- 画像ファイルなし。モンスターは SVG、効果音は Web Audio API で生成している
- ダークモード、「動きを減らす」設定、スマホのセーフエリアに対応
- 構文チェック（`node --check`）と、出題数の検算（上の表）は実施済み。実機・ブラウザでの動作検証は未実施
