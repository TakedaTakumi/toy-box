# ポリリズム／ポリメーター試作

ポリリズムとポリメーターを、**音を聴きながら視覚的に試せる**ブラウザ上の試作です。
リズムの層を最大3つ重ね、円形表示とタイムライン表示を切り替えて、頭が揃う様子やズレの様子を見比べられます。

- 成果物：単一のHTMLファイル（`index.html`）
- 試作リンク：https://takedatakumi.github.io/toy-box/tools/polyrhythm/

## 何を確かめるための試作か

| 問い | この試作での見せ方 |
| --- | --- |
| ポリリズムとポリメーターは何が違うのか | モード切り替えで、同じ層の数でも「1周を割る」か「拍を数える」かの違いを聴き比べる |
| いつ頭が揃うのか | 円形では針が12時に揃う瞬間、タイムラインでは点線で揃う位置を見る |
| 数が変わると周期がどう変わるのか | 層の数を変え、画面下の説明文で揃うまでの長さを確認する |

## 用語（この試作での定義）

| 用語 | 試作での扱い |
| --- | --- |
| ポリリズム | **1周の長さを全層で共通**にし、各層が1周を別々の数で等分する（例：3対2） |
| ポリメーター | **拍の速さを全層で共通**にし、各層が別々の拍数で1小節を数える（例：4/4と3/4） |
| 層 | 同時に鳴らすリズムの1本分。最大3層 |
| 頭 | 各層の周期の先頭の拍。少し大きな音で鳴る |

## 使い方

1. 上部でモード（ポリリズム／ポリメーター）と表示（円形／タイムライン）を選ぶ
2. 「再生」を押す（ブラウザの仕様上、音はボタン操作の後に鳴り始める）
3. 層の数（＋／−）、層のON/OFF、プリセットを変えて聴き比べる
4. テンポ（1周の長さ、またはBPM）のスライダーで速さを変える

## 機能仕様

### モードと設定範囲

| 項目 | ポリリズム | ポリメーター |
| --- | --- | --- |
| 共通のもの | 1周の長さ | 拍の速さ（BPM） |
| 共通値の範囲 | 1.0〜8.0秒（0.1秒刻み、初期値3.0秒） | 40〜200 BPM（初期値120） |
| 層ごとの数 | 分割数 1〜12 | 拍数 2〜9（`n/4`と表記） |
| 層の周期 | 1周の長さと同じ | 拍数 × 1拍の長さ |
| 全層の頭が揃う間隔 | 1周ごと | 各層の拍数の最小公倍数（拍） |

### 層

- 層は3つ。初期状態は層1＝3、層2＝2（どちらもON）、層3＝4（OFF）
- 層は色で区別する。**最後の1層はOFFにできない**
- 層ごとに数を増減できる

### プリセット

| モード | プリセット |
| --- | --- |
| ポリリズム | 3対2 ／ 4対3 ／ 5対4 ／ 2対3対4 |
| ポリメーター | 4/4と3/4 ／ 5/4と4/4 ／ 7/4と4/4 ／ 3/4・4/4・5/4 |

モードを切り替えると、そのモードの先頭のプリセット（3対2、または4/4と3/4）が適用される。

### 音

| 層 | 波形 | 高さ |
| --- | --- | --- |
| 層1 | サイン波 | 880 Hz |
| 層2 | 三角波 | 659.25 Hz |
| 層3 | 矩形波 | 440 Hz |

- 各層の頭は、通常の拍より音量が大きく、少し長く鳴る
- 外部の音源ファイルは使わず、Web Audio APIで生成する

### 円形表示

- 層ごとに同心円のリングを持ち、拍の位置に点を置く。12時の位置が頭
- 3拍以上の層は、点を結んだ多角形を薄く描く
- 針が各層の周期で1周する。拍が鳴った瞬間、その点が約0.2秒光って大きくなる
- ポリリズムでは全層の針が同じ速さで回り、ポリメーターでは層ごとに回る速さが違う

### タイムライン表示

- 層ごとに1行を持ち、拍を点で、小節の頭を縦線で表示する
- 2層以上の拍が重なる位置に点線を引く（頭が揃う位置の確認用）
- 表示範囲：ポリリズムは1周分。ポリメーターは、全層が揃うまでの拍数と24拍のうち短い方
- 再生中は、再生位置の縦線が動き、拍が鳴った瞬間に点が光る

### 変更の反映タイミング

再生中の変更は、種類によって反映のタイミングが異なる。

| 変更 | 反映 |
| --- | --- |
| 層の数、層のON/OFF、プリセット | **全層の頭が揃う次のタイミング**で切り替わる（保留） |
| テンポ（1周の長さ／BPM） | 即時。頭から鳴らし直す |
| モードの切り替え | 即時。頭から鳴らし直す |
| 停止中の変更 | 即時 |

保留中の動作は次のとおり。

- 図と音は現在の設定のまま続き、説明文に「次の頭で○○に切り替わります」と表示する
- 保留中にさらに変更した場合、切り替えのタイミングはそのままで、内容は最新の設定で上書きする
- 保留中に現在の設定へ戻した場合、保留は取り消される
- 切り替えの瞬間は、音と図の両方が時間を戻さずに新しい設定へ移る

## 実装メモ

| 項目 | 内容 |
| --- | --- |
| 構成 | 単一のHTMLファイル（CSS・JavaScriptを内包） |
| 音 | Web Audio API。`AudioContext`の時計を基準に、先読みスケジューラ（25msごとに実行、0.12秒先まで予約）で鳴らす |
| 描画 | Canvas 2D。`requestAnimationFrame`で毎フレーム描画し、音と同じ時計から位置を計算する |
| 高解像度対応 | `devicePixelRatio`に合わせてCanvasの解像度を調整 |
| テーマ | OSのライト／ダーク設定に追従（色はCSS変数で管理） |
| フォント | Google Fonts（Zen Kaku Gothic New）。読み込めない場合は端末の日本語フォントで代替 |
| 外部依存 | フォントのみ。JavaScriptのライブラリは使用していない |
| 設定の保存 | なし（ページを開き直すと初期状態に戻る） |

## 既知の注意点と制約

- ポリメーターで揃うまでが長い組み合わせ（例：3/4・4/4・5/4は60拍）では、保留した変更の反映まで時間がかかる
- ポリメーターの拍子は`n/4`の表記のみで、拍の長さの違いは扱わない（全層が同じ長さの拍を数える）
- テンポを動かすたびに頭から鳴らし直すため、再生中のスライダー操作では拍が途切れる
- ブラウザの仕様により、ページを操作する前は音が鳴らない。また、タブがバックグラウンドの間はタイマーが間引かれ、音が乱れることがある
- スマホのマナーモードなど、端末側の音量設定によっては音が出ない場合がある
- 音色・アクセント位置・各層の音量は、現時点では変更できない
