# とけいのれんしゅう

アナログ時計とデジタル表示を並べて、**分単位まで時計を読む**練習をするためのブラウザ試作です。対象は小学校1〜3年生を想定しています。

- 成果物：単一のHTMLファイル（`index.html`）
- 試作リンク：https://takedatakumi.github.io/toy-box/tools/clock-learning/

## 操作

| 操作 | 動作 |
| --- | --- |
| 竜頭を右にドラッグ（またはタップ、「竜頭をひく」ボタン） | 竜頭が引き出され、秒針が止まる |
| 引き出したまま竜頭を上下にドラッグ（またはホイール、↑↓キー） | 長針が回り、短針も連動して動く |
| デジタルの▲▼ | 時・分を1つずつ変える（押し続けると連続で変わる） |
| 竜頭を左にドラッグ（またはタップ、「竜頭をおしこむ」ボタン） | 合わせた時刻から秒針が動き出す |

## 設計上の決め事

- 短針と長針は、デジタルの「時」「分」と同じ色にして、針と数字の対応が分かるようにしている
- 文字盤には、時の数字（1〜12）と分の数字（5〜60）を表示する。分の数字は切り替えで隠せる
- 竜頭を回したときは、長針が1周すると短針が進む（時計と同じ連動）
- デジタルの分の▲▼は、時を繰り上げずに0〜59で循環する
- 時刻の変更は、竜頭を引き出している間だけ有効にしている
- 表示は12時間（午前・午後つき）が初期値で、24時間表示に切り替えられる
- 時刻の入力は▲▼とドラッグのみで、数値の直接入力は持たない（不正な時刻が入らない）
