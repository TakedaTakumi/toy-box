# グレゴリー曲面モデラ（Rust 版）

[グレゴリーメッシュエディタ試作](../gregory-mesh-editor/)（JavaScript）の曲面の数学を Rust に移した `gregory-core` を使い、**ケージから組み立てたグレゴリー曲面を GPU で描く**ブラウザアプリです。この段階では、表示の設定に加えて、点・辺・面の選択、移動ハンドルやドラッグでの移動、元に戻す・やり直しができます。押し出し・ループ分割・削除・折れ目・ミラーはまだできません。

- 成果物：WebAssembly（Rust + egui + wgpu）。WebGPU に対応したブラウザでは WebGPU、そうでなければ WebGL2 で描く
- デスクトップ版：`cargo run -p gregory-editor` でも同じ画面が開く

## 何を確かめるための段階か

| 問い | この段階での見せ方 |
| --- | --- |
| `gregory-core` の出力を、そのまま GPU で描けるか | プリセットのケージから曲面を組み立て、深度バッファ付きで描く |
| egui の画面構成で、JS 試作と同じ情報を出せるか | 左にツール、右に連続性の検証、下に頂点数や UI 処理の CPU 時間（前フレーム分。GPU 時間は含まない）を出す |
| WebGPU と WebGL2 の両方で同じ見た目になるか | 使っているバックエンドをステータスバーに出す |
| JS 試作と同じ編集の手触りを egui で作れるか | 選択・ピック・移動ハンドル・元に戻す/やり直しを、JS 試作と同じしきい値と挙動で移す |

## 使い方

1. 左のツールパネルの「形状」で、立方体・平面・四角錐・三角柱から選ぶ（いまの形を置き換える。元に戻せる）
2. 「選択」で点・辺・面のモードを選び、3D ビューで要素をクリックして選ぶ
3. 選んだ要素か、移動ハンドルの矢印・四角をドラッグして動かす
4. 「表示」で、スムース／フラット、曲面とケージの表示、分割数を切り替える
5. 空所をドラッグして回し、ホイール（またはピンチ）で拡大縮小する
6. 右のプロパティパネルで、選択の状態、G0・G1 の検証結果と形の数を確かめる

### 操作

| 操作 | 内容 |
| --- | --- |
| クリック | いまのモードの要素を選ぶ（ほかの選択は外す） |
| `Shift` / `Ctrl`（Mac は `Cmd` も）+ クリック | 選択に足す。選択済みの要素なら外す |
| 選択済みの要素をドラッグ | 選択を保ったまま移動する（軸を固定していれば、その軸に沿って） |
| 移動ハンドルの矢印 / 四角をドラッグ | その軸に沿って / その平面の上で移動する |
| `X` / `Y` / `Z` | 要素のドラッグをその軸に固定する。同じキーで自由に戻す |
| `1` / `2` / `3` | 点 / 辺 / 面のモード。いまの選択を新しいモードの要素に変換する |
| `Ctrl` + `A` | いまのモードの要素をすべて選ぶ |
| `Esc` / 空所をクリック | 選択を解除する（空所のクリックは、`Shift`・`Ctrl` 付きなら解除しない） |
| `Ctrl` + `Z` | 元に戻す |
| `Ctrl` + `Shift` + `Z` / `Ctrl` + `Y` | やり直し |
| 空所をドラッグ / 右・中ボタンでドラッグ / `Alt` + ドラッグ | 視点を原点のまわりに回す（上下は ±約 83° まで） |
| ホイール / ピンチ | 拡大縮小（カメラの距離 3〜16）。移動のドラッグ中にピンチすると、移動を取り消す |
| 空所をダブルクリック | 視点を初期位置に戻す（「視点をリセット」ボタン・「表示」メニューと同じ） |
| `S` | スムースとフラットの切り替え |
| 「編集」メニュー | 元に戻す・やり直し・全選択・選択解除 |
| 「表示」メニュー | 左右のパネルの開閉、表示の切り替え |

テキスト入力にフォーカスがあるときは、キーボードの操作は効かない。移動や回転のドラッグ中は、`S` 以外のキーボードの操作と、パネル・メニューの編集の操作を受け付けない。

## 機能仕様

| 項目 | 内容 |
| --- | --- |
| プリセット | `gregory-core` の `PRESETS`（立方体・平面・四角錐・三角柱）。ハンドル長は 1、接線場は G1 |
| 分割数 | 4〜16（初期値 8）。範囲外の値は範囲に丸める |
| スムース | `gregory-core` の頂点法線をピクセルごとに補間して光を当てる |
| フラット | 細かい三角形ごとに頂点を分け、三角形の面法線で光を当てる |
| 光の当て方 | JS 試作と同じ（カメラから見て左上手前の平行光、環境光、弱いハイライト）。裏面も表と同じように照らす |
| ケージ | 辺を直線、頂点を小さな四角で描く。折れ目の辺は橙色。線と点は常に曲面の手前に重ねて描く |
| ベジェ曲線 | 辺の曲線（`build_model` の辺のベジェを 24 分割した線分）を、ケージの上に重ねて描く。折れ目の辺は橙色、選んだ辺は橙色（選択の色）。選択の判定と同じ曲線で、表示を切っても判定は変わらない |
| 連続性の検証 | G0 は共有辺の位置の最大の隙間、G1 は滑らかな共有辺の法線の最大差（度）。0.5° 未満を「G1 成立」とする（JS 試作と同じ） |
| 選択 | モードは点・辺・面。点は画面上 13 未満、辺は曲線（`build_model` の辺のベジェを 24 分割した折れ線）から 10 未満で最も近いもの、面は画面上で位置を含む三角形のうち最も手前のもの。いずれも裏向きのものは選ばない（JS 試作と同じ判定。距離の単位はポイント） |
| 選択の表示 | 選んだ点は大きく橙色、選んだ辺は曲線を橙色、選んだ面は曲面に橙色を混ぜる（割合 0.55）。点はモードが点のとき大きめに描く |
| 移動ハンドル | 選んだ頂点の平均の位置に、画面上で長さ 84 の X・Y・Z の矢印と、XY・YZ・ZX の平面の四角（軸の 0.22〜0.5）を描く。四角を矢印より優先し、矢印は軸から 9 未満でつかむ。ホバー中とつかんでいる間は橙色。中心がカメラの手前 0.1 未満なら出さない |
| 移動量 | 自由：画面上の移動量を中心の奥行きで換算し、カメラの右・上へ。軸：移動量を軸の画面上の向きへ射影。平面：視線と平面の交点の差。ドラッグは移動量（\|dx\| + \|dy\| の累計）が 3 を超えてから動き出す |
| 元に戻す / やり直し | コマンド方式。頂点の移動は、対象の頂点と移動前・移動後の位置を、形の置き換えは前後のケージを持つ。最大 100 件。新しい操作でやり直しの履歴は消える。元に戻す・やり直しの後は、選択を空にする（モードは変えない） |
| 取り消し | 移動のドラッグ中に、2本目の指が触れる（ピンチ）か、タッチが取り消されるか、ウィンドウのフォーカスが外れたら、頂点を開始時の位置に戻し、履歴には積まない |
| 再計算 | ケージが変わる（版番号が増える）か分割数が変わったときだけ曲面を組み立て直す。シェーディングや選択が変わったときは GPU に送る配列だけを作り直す |

## 既知の制約

- 押し出し、ループ分割、削除、折れ目、ミラーはまだない
- ハンドル長は 1 で固定。ベジェ曲線と制御点、座標軸は描かない
- 選んだ辺は線の色だけを変え、太さは 1 ピクセルのまま
- ケージやベジェ曲線を隠しても、点・辺はピックできる（JS 試作と同じ）。選んだ点の表示はケージと、選んだ辺の表示はベジェ曲線と一緒に隠れる
- ケージの線と点、ベジェ曲線は常に曲面の手前に重ねて描き、裏向きの頂点・辺・曲線の区間を隠す処理は未対応（ピックは表向きの区間だけ）
- 線は 1 ピクセルの太さで、アンチエイリアスはかけない（MSAA を使わないため、曲面の輪郭もギザギザが出る）
- 表示の設定は保存しない（ページを開き直すと初期状態に戻る）
- WebGPU と WebGL2 のどちらにも対応していないブラウザでは、起動時に失敗した旨を表示して止まる。起動後に Rust 側で panic したときは、再読み込みを促す表示を出す。wasm の取得・初期化そのものに失敗した場合は、20 秒たっても読み込み中の表示が消えなければ、失敗した可能性を案内する

## 実装メモ

| 項目 | 内容 |
| --- | --- |
| 構成 | Rust + egui 0.37（eframe）+ wgpu 30。曲面の数学は `crates/gregory-core` |
| 描画 | egui の paint callback（`egui_wgpu::Callback`）の中で、自前の WGSL のパイプラインで描く。深度バッファは 24 ビット（`Depth24Plus`）、MSAA なし |
| 座標系 | 右手系の Y-up。カメラの初期値と焦点距離（ビューの短い辺 × 1.55）は JS 試作と同じ |
| 画面 | egui 標準のダークテーマ。上にメニューバー、左にツール、中央に 3D ビュー、右にプロパティ、下にステータスバー。狭い画面では左右のパネルを閉じて始める |
| フォント | HackGen を改変した Gregory UI Sans（SIL Open Font License 1.1）。UI で使う文字だけに絞っている |
| ビルド | `crates/gregory-editor` で `trunk build --release`。出力先は `public/tools/gregory-modeler/`（生成物のため Git では追跡しない） |

## ファイル構成

```
crates/gregory-editor/
├─ Cargo.toml
├─ Trunk.toml           # trunk の設定（出力先など）
├─ index.html           # trunk の入力（canvas と読み込み中の表示）
├─ README.md            # このページ
├─ assets/fonts/        # UI のフォントとライセンス（LICENSE 類は fonts/ に公開する）
└─ src/
   ├─ main.rs           # ネイティブと web の起動
   ├─ lib.rs
   ├─ app.rs            # アプリの状態と 1 フレームの処理
   ├─ settings.rs       # 表示の設定
   ├─ scene.rs          # 編集中のケージから曲面を組み立てる
   ├─ shortcuts.rs      # キーボードのショートカットの割り当て
   ├─ editing/          # 選択・ピック・移動ハンドル・ドラッグ・履歴（egui に依存しない）
   ├─ memo.rs           # 入力が変わったときだけ計算し直す入れ物
   ├─ mesh_buffers.rs   # GPU に送る頂点・インデックス・線分・点の配列
   ├─ camera.rs         # オービットカメラと変換行列、画面への射影と視線
   ├─ readouts.rs       # 検証結果・数・バックエンド名の表示用の値
   ├─ palette.rs        # 3D ビューの色
   ├─ fonts.rs          # フォントの登録
   ├─ panels/           # メニューバー・ツール・プロパティ・ステータスバー
   └─ viewport/         # 3D ビューの入力の振り分け、移動ハンドルの描画、wgpu の資源、WGSL シェーダ
```
