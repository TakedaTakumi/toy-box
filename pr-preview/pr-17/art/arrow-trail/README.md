# やじるしコンバット 仕様書

- 試作リンク：https://takedatakumi.github.io/toy-box/art/arrow-trail/

## 概要と目的

エースコンバットのリザルト画面にある「矢印で描いた機体の軌跡」を、ブラウザで眺めて楽しむ3Dアニメーションとして再現し、ミサイル戦まで広げたものです。

矢印の機体が飛び回り、後ろに帯状の軌跡を引きます。モードを切り替えると、攻撃側が標的を追ってミサイルを一斉射する「追撃戦」と、2チームが互いに攻撃し合う「交戦」を眺められます。1つのHTMLファイルで動き、Three.js（r128）で描画します。保存されるデータはありません。

[やじるしコンバット](./)の仕様を書いています。機体座標系の飛行モデル、スロットル、交戦モード、耐久力と撃墜、補充、真上カメラを備えます。

## 画面構成と操作

画面は、全面の3D表示と、右下の設定パネルで構成します。モードは3つ、視点は3つ（斜め、真上、主観。主観は、追撃戦と交戦のときだけ）あり、追従カメラは独立したスイッチです。

**モード**

1. 軌跡だけを眺める: 機体が自由に飛ぶ。ときどき宙返りなどを見せる（初期値）
2. 追撃戦（ミサイルと回避）: 攻撃側が標的を追い、標的は回避する
3. 交戦（互いに攻撃）: 2チームが互いに攻撃し、回避する

**視点と追従カメラ**

- 視点は「斜め」と「真上」。切り替えるとカメラがなめらかに移る。真上でも、ドラッグで画面を回せる
- 視点「主観」は、追従カメラで追っている機体の、機首の少し前・少し上から、前を見る。追撃戦と交戦のときだけ選べる。選ぶと、追従カメラが自動でオンになる。追従カメラをオフにする、またはモードを軌跡だけにすると、斜めに戻る
  - カメラは、機体の向き（ロールを含む）に合わせて動く。宙返りやバレルロールは、画面の回転として見える。視野角は約70度で、霧は固定の距離
  - 追っている機体の矢印と、地面への線、エースの光輪は、視界をさえぎるので、消す（ほかの機体は、そのまま）
  - ドラッグで、機首の向きから、左右（±120度）・上下（±60度）に見回せる。離すと、ゆっくり前向きに戻る。ホイールとピンチは、使わない。「カメラを自動で回す」も、働かない
  - 追っている機体が撃墜されたら、カメラは、撃墜された場所で止まる。自動切り替えがオンなら、余韻のあと、次の機体の主観に切り替わる
  - 空を向いたときも、動きが分かるように、目印を2つ出す（どちらも、主観のときだけ。設定パネルの「星空（主観）」「姿勢表示（主観）」で、別々にオン・オフできる。初期はどちらもオン）
    - 星空: 世界に固定した、約1500個の星を、遠い球面の上半分に置く。カメラの位置に合わせて動かすので、機体が進んでも動かず、向きを変えたときだけ動く。回転の向きと速さが分かる。星の配置は、いつも同じ
    - 姿勢表示: 画面の中央に、機首の目印と、水平線（0度）、ピッチの目盛り（10度おき、±80度）、ロールの目盛り（30度おき、±90度）を重ねる。水平線は、世界の上下に合わせて傾き、ピッチに合わせて動く。水平線より下（地面側）の目盛りは、破線。見回したときは、カメラの向きに合わせる
  - 画面左上のヒントは、主観のあいだ、「ドラッグで見回す（離すと前向きに戻る）」になる
- 追従カメラは、追撃戦と交戦で使えるチェックボックス。詳細は「追従カメラの仕様」を参照

**画面の表示**

- 左上: タイトルと操作のヒント。追従カメラがオンのときは、追っている機体の耐久力
- 右上: 撃墜数（交戦のみ）
- 右下: 設定パネル。「設定」ボタンで開閉する。広い画面では初期で開き、狭い画面では閉じる

**カメラ操作**

- ドラッグで回転、ホイールとピンチで拡大縮小（距離80〜520。「戦闘領域の広さ」が×1.0より広いときは、上限が、広さに合わせて伸びる）。初期の距離は260で、縦長の狭い画面では400
- 真上では、左右のドラッグで画面を回す。上下のドラッグは無効
- 「カメラを自動で回す」は初期でオン。OSの「視差効果を減らす」設定では、初期でオフ
- 「最初から」で配置を作り直し、「一時停止」で動きを止める（カメラ操作は可能）
- 「戦闘領域の広さ」（×0.5〜×3.0、初期は×1.0）で、機体が飛ぶ範囲と地形の広さを変える。広くすると、機体どうしの距離が伸びて、ミサイルを撃つ機会が増える。飛行の限界と地形は、動かすとすぐ変わる。機体の最初の配置は、「最初から」を押したときに、新しい広さで作り直される。地形は、広さに合わせて格子の間隔も変わる（頂点の数は同じ）

## 飛行モデル

機体の姿勢をクォータニオンで持ち、ロール・ピッチ・ヨーの角速度を機体の軸で積分します。旋回は「機体を傾けて機首を引く」ことで生まれ、進行方向は常に機首の向きです。

**姿勢と操縦**

- 軸は、機首が+Z、右翼が+X、上が+Y
- 角速度には上限があり、応答に遅れがある（ロール約7/秒、ピッチ約5/秒、ヨー約4/秒の追従）
- ピッチの上限は「許容G × 重力 ÷ 速度」（最大2.4rad/秒）。速度が約8〜20のときは、舵が効きにくい
- パイロットは、進みたい方向を機体座標で見て、誤差が大きければ傾けて引く。目標が揚力の反対側にあるときは、軽く押し下げる。誤差が小さければ翼を水平に保ち、方向舵で微調整する

**スロットルと速度**

- 加速度 = 推力 − 空気抵抗 − 旋回の負荷による抵抗 − 重力の機首方向成分
- 推力は、スロットル（0〜1、アフターバーナーは1.3）× 18。空気抵抗は 0.01 × 速度²。旋回の負荷は、荷重倍率 n に対して 0.12 × (n² − 1)。重力は12
- 上昇すると減速し、降下すると加速し、急旋回で速度が落ちる。速度の範囲は9〜75
- 巡航中は、目標速度（個体ごとに約25〜35）をオートスロットルで保つ

**通常飛行**

- ゆるやかに進路を変え、地面から約18〜62の高さ（最大85）を保つ
- 14〜28秒ごとに、見せ場の機動を行う。宙返り、インメルマンターン、バレルロールで、範囲の中心寄り（半径の約0.6倍以内）でだけ始める。宙返りの前には、速度36まで加速する

**安全処理（最優先）**

- 地面や前方の地形に近づくと、引き起こす
- 飛行範囲（半径125。「戦闘領域の広さ」で変わる）の約0.6倍を超えると、中心へ戻る向きに寄せる。1.2倍を超える、または高さが135を超えると、機動を打ち切って戻る
- 高さが100を超えると降下する。速度が17未満になると、機動をやめて加速し、機首を下げる

**1ステップの流れ**

1. 状況から、進みたい方向、操縦の限界、スロットルを決める
2. 進みたい方向から、ロール・ピッチ・ヨーの指令を作る
3. 指令を、上限と遅れのある角速度にする
4. 姿勢を更新し、速度と位置を進める

## 機体と軌跡の表現

機体は平たい矢印で、軌跡は翼端を結ぶ帯です。帯はロールに合わせてねじれるので、回転の履歴が軌跡に残ります。

**矢印**

- 平たいダーツ形（長さ約3.6、翼幅3.0に、大きさの倍率を掛ける。初期は×1.5）。半透明の塗りと、明るい縁取り
- 機体の向き（ロール・ピッチ・ヨー）に合わせて表示する
- 被弾すると、白く光る
- 機体から地面へ、細い線を引く（高さの目安）

**軌跡（帯）**

- 左右の翼端を結ぶ帯。帯の幅は、矢印の大きさに連動する
- 古い部分ほど薄く、先頭は透明から始まって、約6単位かけて濃くなる（矢印と重ならないため）
- 長さは50〜1500点（初期450）。加算合成で描く
- 撃墜された機体の軌跡は、約2.2秒かけて薄れる

**地形と背景**

- 地形は、ワイヤーフレーム。高いほど明るく、中心から離れるほど薄い。表示は切り替えられる
- 地形の高さは、Inigo Quilez の「morenoise」方式で作る（`terrain.js`）。勾配付きバリューノイズ（quintic補間）を、オクターブごとに回転しながら足し、勾配が大きい所ほど振幅を抑える（`a += amp * n.x / (1 + dot(d, d))`）。単純なfBmやPerlinノイズの重ね合わせは使わない。尾根や谷がなめらかで、平地には細かい起伏が残る
- 高さは、0以上、45以下。平均は約12（シードによって、約8〜15）。同じシードなら、必ず同じ地形になる。地形の描画も、地面への衝突、地面すれすれでの引き起こし、ミサイルの地面爆発も、同じ高さ関数を使う
- オクターブは4、最も粗い波長は約110。地形の線（格子の間隔は5。広さに合わせて変わる）で表せないほど細かい凹凸は、作らない
- 霧は、カメラの距離に連動する。遠くの機体は、霧の中から姿を現す
- 背景は、暗い紺色

**色**

| モード | 色 |
| --- | --- |
| 軌跡だけ | 水色、氷色、水色、琥珀を、機体の順に繰り返す |
| 追撃戦 | 攻撃側は水色。逃げる側は氷色と琥珀を交互 |
| 交戦 | チームAは水色系、チームBは琥珀系 |

## 追撃戦モード

攻撃側が標的を追ってミサイルを一斉射し、逃げる側（標的）が回避します。攻撃側は被弾しません。攻撃側の1機は、開始時からエース機です（「エース機」を参照）。

**構成**

- 攻撃側と逃げる側の数を、別々のスライダーで指定する（各0〜16、初期は4と4）
- 最初は、標的が中央寄りに散らばり、攻撃側は、どれかの標的の後方80〜110に付く

**攻撃側**

- いちばん近い標的を狙う。0.3秒ごとに見直し、明らかに近い標的が現れたときだけ切り替える（距離の比が約1.22倍以上）
- 標的を先読みして追う。距離が32未満（機銃がオンなら20未満）になると、機首を上げて距離を取る。距離が100を超えると、アフターバーナーで追う
- 位置取り: ミサイルを撃てる状態（次の発射まで待ち時間がなく、機動中でない）のとき、または機銃がオフのときは、自分のミサイルの発射距離に合う距離を保つ。
  - 標的が、ミサイルの最短距離（「ミサイル」の表の発射距離の下限）より近いときは、いったん離れる。標的と反対の向きへ、少し上昇しながら、アフターバーナーで進み、最短距離の1.6倍に達したら、機首を標的へ戻す。離れるのは、最長で3秒。撃ったとき（待ち時間に入ったとき）も、やめる
  - 標的が、最大距離の0.85倍より遠いときは、アフターバーナーで詰める
  - 撃ったあとの待ち時間は、機銃がオンなら、今までどおり、近づいて機銃を使う（近すぎたら、機首を上げて距離を取る）。機銃がオフなら、距離を保つ
  - 回避機動中は、位置取りより、回避を優先する
- ミサイルを撃つ条件は、距離が撃つミサイルの発射距離（「ミサイル」の表を参照）の範囲内で、機首と目標のなす角が0.5rad未満で、機動中でないこと
- 一斉射の数は設定（初期9発）。発射の間隔は0.04秒で、次の一斉射まで5〜8秒空ける（熱誘導型とレーダー誘導型の場合。大型は、2発を0.3秒おきに撃ち、次まで4〜5秒空ける。設定の数には従わない）

**逃げる側**

- 自分に向かうミサイルが距離95未満に近づくと、回避機動に入る。機銃で後ろから狙われているときも、距離110未満で回避機動に入る（正面から向かい合っているときは回避しない）。ブレイクターン、切り返し、バレルロール、スプリットSから、ランダムに選ぶ。ロール系が続かないように、間を空ける
- ミサイルが距離100未満に近づくと、囮を6発撒く。向かってくるいちばん近いミサイルが熱誘導ならフレア、レーダー誘導ならチャフを撒く（大型には、囮を撒かない）。発射の間隔は0.09秒で、次の使用まで2.2秒空ける（フレアとチャフは、別々に数える）
- 回避機動の間は、スロットルを絞る（減速して相手に追い越させる）か、アフターバーナーを使う

## 交戦モード

2チームが向かい合って戦い、全機が「攻撃」と「回避」の両方を行います。ミサイルは敵だけを狙い、味方には当たりません。

**構成**

- チームAとチームBの数を、別々のスライダーで指定する（各0〜16、初期は4と4）
- 最初の配置は、チームAが左側（東向き）、チームBが右側（西向き）で、向かい合って飛ぶ
- 色は、チームAが水色系、チームBが琥珀系

**全機の動き**

- いちばん近い敵を追い、攻撃の条件が揃えばミサイルを一斉射する（条件と、ミサイルの発射距離に合う位置取りは、追撃戦の攻撃側と同じ）
- 自分に向かうミサイルが近づくと、回避を最優先する。回避機動とフレア・チャフは、追撃戦の逃げる側と同じ
- 全機に耐久力がある。耐久力と撃墜は「ミサイル・機銃・耐久力・撃墜」を参照

**エース機**

- 「エース機」チェックボックス（初期はオン）で、使うかどうかを選べる。追撃戦と交戦でだけ表示される
- 開始時は、交戦は各チームの先頭の1機、追撃戦は攻撃側の先頭の1機が、エースになる。逃げる側（追撃戦）は、攻撃しないので、エースにならない
- 機体ごとに撃墜数を数え、3機を撃墜した機体は、エースに昇格する（エースの数に上限はない）。ミサイルと機銃のどちらで撃墜しても、撃った機体の撃墜数になる。撃った機体が先に撃墜されていたときは、数えない
- 撃墜されると、撃墜数とエースの状態はなくなる。補充機は、普通の機体
- エースの性能は、耐久力が1.5倍（切り上げ、最低でも+1）、旋回の速さが10%向上、一斉射が+2発（大型は、2発のまま）。昇格のときは、増えた耐久力の分だけ、現在の耐久力も増える
- エースの見た目は、チームの色のまま（塗りと軌跡）で、輪郭を金色にし、機体の周りに金色の光輪を付け、軌跡を少し明るくする。チームと、エースであることの両方が分かる。昇格の瞬間に、金色の閃光と火花を出す。追従カメラのHUDには、「ACE」と撃墜数を出す
- オフにすると、その場で全エースが普通の機体に戻る（見た目と性能も戻る）。オンにすると、開始時のエースは「最初から」を押したとき（またはモードを切り替えたとき）に作られる。オンにしたあとは、戦闘の途中から、撃墜数による昇格も起きる
- 軌跡だけを眺めるモードには、エースはいない

**スコア**

- 右上に「チームA　n : n　チームB」の形で、撃墜数を表示する
- 撃墜数は、撃墜したミサイル（または機銃）を撃った側のチームに加算される
- 「最初から」やモードの切り替えで、0に戻る

## ミサイル・機銃・耐久力・撃墜

ミサイルにはエネルギーがあり、旋回すると速度が落ちます。標的の回避機動やスロットル操作が効くので、ミサイルが標的の近くで爆発する割合は、発射数の約1〜2割です（模擬実行での値）。

ミサイルには、性能の違う3種類があります（熱誘導型、レーダー誘導型、大型）。撃つ機体ごとに、種類が決まっています。

| 項目 | 熱誘導型（近距離・高機動） | レーダー誘導型（長距離・高速） | 大型（現実寄り・高威力） |
| --- | --- | --- | --- |
| 撃ち方 | 一斉射（設定の数）、扇状にばらけて発射 | 一斉射（設定の数）、扇状にばらけて発射 | 2発を0.3秒おきに、機首へまっすぐ発射 |
| 次の発射までの間 | 5〜8秒 | 5〜8秒 | 4〜5秒 |
| 初速 | 機体の0.9倍（最低28） | 機体の0.9倍（最低28） | 機体の1.5倍（最低60） |
| 推進剤の燃焼時間 | 1.6〜2.2秒 | 2.4〜3.2秒 | 2.8〜3.6秒 |
| 最大旋回G | 12〜15 | 8〜10 | 6〜8 |
| 推力（燃焼中の加速） | 42 | 48 | 50 |
| 寿命 | 5〜6.5秒 | 7〜9秒 | 9〜11秒 |
| 発射距離 | 35〜150 | 50〜230 | 80〜260 |
| 惑わされる囮 | フレアだけ | チャフだけ | どちらにも惑わされない |
| 命中時の耐久力の減り | 1 | 1 | 2 |
| 命中時の爆発 | 通常 | 通常 | 通常の約1.8倍 |
| 軌道の膨らみ（らせん） | あり | あり | なし（素直に追尾） |
| 先端の色・大きさ | 暖色、通常の点 | 寒色、通常の点 | 橙赤色、大きな点（通常の約2.4倍） |

- 種類は、機体を配置するときに、3種類を均等（各約33%）にランダムに決まる。決まった種類は、その機体がいるあいだ変わらない。補充機は、新しく決まる

**ミサイル**

- 熱誘導型とレーダー誘導型の一斉射では、機首から約30〜70°の扇状にばらけて発射する。大型は、機首の向きにまっすぐ発射する。初速は、上の表のとおり
- 推進剤が燃えているあいだ（燃焼時間は、上の表のとおり）は加速する。燃え尽きたあとは、空気抵抗（0.004 × 速度²）と、旋回による負荷で減速する
- 旋回できる角速度は、「最大旋回G（上の表のとおり）× 重力 ÷ 速度」で決まる。速度が高いほど、曲がれない
- 標的への視線に、減衰する回転成分を足して、大きならせんを描く（板野サーカス風の軌道。大型は、らせんを描かない）。地面すれすれでは、機首を上げる
- 近接信管の距離は、標的が3.5、囮（フレア・チャフ）が4。熱誘導型はフレア、レーダー誘導型はチャフに、約80%が惑わされる（1回だけ）。合わない囮は、無視する。大型は、どの囮にも惑わされない。標的が消えたら、別の標的を狙い直す
- 寿命は、上の表のとおり。推進剤が切れて0.5秒後に、速度が20未満になると自爆する。地面にも爆発する。範囲の外（中心から±320。「戦闘領域の広さ」が×1.0より広いときは、広さに合わせて伸びる）や、高さ240を超えても自爆する
- 白い煙の軌跡を引き、消えるまで約2.2秒かけて薄れる

**フレアとチャフ**

- フレアは、約2.6秒で消える明るい粒。ミサイルが近づくと、標的が撒く。熱誘導型を惑わす
- チャフは、約3秒でゆっくり広がる淡い緑白の粒で、フレアより長く漂う。レーダー誘導型を惑わす
- 囮は、撒いた機体のものだけに効く。ミサイルが追っている標的が撒いた囮の中から、近いものを選ぶ

**機銃**

設定パネルの「機銃」チェックボックスで切り替える（初期はオン）。数値は、コードの定数から転記しています。

- 射程110、最短距離22。機首と目標のなす角が約8°（0.14rad）未満のときに撃ち始める
- 連射の間隔は約0.055秒（約18発/秒）。1回の連射は1.2〜2.4秒で、次まで1.0〜2.5秒空ける
- 1発のダメージは0.05（約20発で、ミサイル1発分）

**耐久力と撃墜**

- 「耐久力（被弾に耐える回数）」は1〜10で、初期は4。ミサイルの命中は1（大型は2）、機銃の1発は0.05を引く
- 被弾できるのは、追撃戦では逃げる側だけ、交戦では全機
- 耐久力が0になると撃墜される。大きな爆発とともに矢印が消え、軌跡は別枠で約2.2秒薄れる
- スライダーを動かすと、生きている機体の耐久力は、残りの割合を保って換算される

**爆発**

- 閃光、火花、衝撃リングで表現する。撃墜時の爆発は、ミサイルの爆発より大きい

## 補充と飛来

撃墜された機体の分は、設定した時間が経つと、遠方から飛来する新しい機体で補われます。数は、常に保たれます。

**撃墜から補充まで**

1. 耐久力が0になると、機体が爆発して消える。軌跡は、別枠（最大24枠）に写して、約2.2秒かけて薄れさせる
2. 「補充までの時間」（0〜5秒、0.5秒刻み、初期0秒）が経つと、同じ枠に新しい機体を出す。耐久力は満タンで、軌跡も新しく始まる
3. 補充機は、範囲のはるか外（中心から、飛行範囲の半径＋475。広さ×1.0で約600。高さ50〜90）に現れ、戦場の中心付近へ向けて、速度70で直進する
4. 中心から半径の約0.95倍に入ると、到着したとして、通常の機体に変わる（到着まで約7秒）

**飛来中の扱い**

- 敵に狙われず、ミサイルの標的にならない。カメラの追従の対象にもならない
- 霧の中から、小さな点として姿を現す
- 出現する方向は、交戦では自陣側（チームAは左側、チームBは右側）、追撃戦ではランダム

**数のスライダーを増やしたとき**

- 追撃戦と交戦では、増えた機体も、遠方から飛来して加わる
- 軌跡だけを眺めるモードでは、増えた機体は、その場に散らばって現れる

## 追従カメラの仕様

追従カメラは、追う機体を常に画面の中心にとらえます。追撃戦と交戦でだけ使え、追っていた機体が撃墜されると、カメラはその場で停止します。

**基本**

- 「追従カメラ」をオンにすると、カメラの距離が140になる。オフにすると、元の距離と位置に戻る
- カメラの注視点が、追う機体をなめらかに追う。ドラッグでの回転と拡大縮小は、追従中も使える

**追う機体の選び方**

- 追従するチームを選べる。交戦は「チームA／チームB／両方」（初期は両方）、追撃戦は「攻撃側／逃げる側／両方」（初期は逃げる側）。モードを変えると、そのモードの初期値に戻る
- 追える機体の条件は、生きていて、飛来中でなく、選んだチームに属すること
- 「次の機体」ボタンで、選んだチームの機体を、枠の順に切り替える
- チームの選択を変えると、追っている機体が選んだチームでなければ、そのチームのいちばん近い機体へ、すぐ切り替わる。追っていた機体が撃墜済みでも、切り替わる。追える機体がいないときは、現れるまでカメラが待つ

**撃墜されたとき**

- 追っていた機体が撃墜されると、カメラはその場で停止する。補充機が同じ枠に出ても、自動では移らない
- 「撃墜されたら自動で次の機体へ」をオンにすると（初期はオフ）、撃墜位置にいちばん近い、追える機体へ自動で切り替わる。切り替えは、撃墜から「切り替えまでの間隔」（0〜5秒、初期2秒）が経ってから行う。そのあいだ、カメラは撃墜された場所で止まる（余韻）。0秒なら、すぐ切り替える。余韻のあいだに、「次の機体」ボタンや、追従するチームの変更を操作したら、その場で切り替わり、待ち時間はなくなる

**表示（左上）**

- 「追従中: チームA 3番機　ミサイル: 熱誘導　耐久力 2 / 4」の形で、機体、撃つミサイルの種類、耐久力を表示し、耐久力のバーを添える。25%以下では、バーが琥珀色になる。エース機は、機体の前に「ACE」が付く。撃墜数が1以上の機体（エース機は常に）は、「撃墜 n」も表示する（ミサイルのあと、耐久力の前）
- ミサイルの種類は、「熱誘導」「レーダー誘導」「大型」のいずれか。ミサイルを撃たない、追撃戦の逃げる側の機体では、表示しない
- 撃墜後は「撃墜されました（「次の機体」で切り替え）」。自動切り替えがオンのときは、「撃墜されました（あと2秒で次の機体へ）」のように、残りの秒数を出す。追える機体がないときは「追える機体がありません」と表示する
- 追撃戦で攻撃側を追うときは、被弾しないので、耐久力は表示しない

## 検証状況・制限・保留事項・決定の経緯

動作は、描画を除く模擬実行（ヘッドレス）で確認しました。実際の見た目と描画の負荷は、ブラウザでの確認が必要です。

**検証した内容（模擬実行）**

- 通常飛行（120秒分）で、地面への接近や不正な値は出なかった
- 追撃戦のミサイルが、標的の近くで爆発する割合は、発射数の約1〜2割
- 交戦4対4（耐久力4）の120秒間で、撃墜は約14〜25回。補充機の到着は平均6.9秒。チームAは左側、チームBは右側から出現した
- 16対16では、同時に飛ぶミサイルが最大約100発
- 補充までの時間を0秒と3秒にして、設定どおりに補充され、撃墜された軌跡が途中で消えないことを確認した
- 追従カメラの停止、次の機体、自動切り替え、チーム固定は、すべて動作した
- 交戦8対8の60秒間（速度×3）を2回で、ミサイルは熱誘導型が1188発、レーダー誘導型が567発、大型が46発（種類は機体ごとのランダムなので、数は実行ごとにばらつく）。標的の近くで爆発した割合は、熱誘導型が約16%、レーダー誘導型が約7%、大型が約30%（大型は発射数が少ない）。フレアとチャフは、それぞれの誘導方式のミサイルだけを惑わし、大型は惑わされなかった。追撃戦と交戦16対16でも、エラーは出なかった。（大型の前の設計では、扇状に発射して旋回が鈍く、命中率が約3%だった）
- 戦闘領域の広さを×0.5、×1.0、×2.0、×3.0にして、交戦8対8を45秒（速度×3）動かした。発射の条件（距離、向き、機動中でない）が揃う時間の割合は、大型で、順に約0.2%、1.3%、4.2%、14%と増えた（熱誘導型は約2.5%、6.8%、12.9%、19%）。大型の発射数は、4発、20発、40発、82発だった。最短距離より近すぎる時間の割合も、大型で、約97%、90%、76%、63%と減った。どの広さでも、エラーは出なかった
- 地形の高さ関数を、`fast-check` のプロパティベーステストで検証した（`npm test`）。決定性、高さの範囲（有限、0以上、45以下）、傾斜の上限（実測の最大は約1.8、テストの上限は3）、不正な入力（NaN、無限大、範囲外、数でない値）への振る舞い、シードの丸め、シードによる地形の違い、勾配と数値微分の一致を確認する。9件が通る
- 地形のシードを変えて、交戦8対8を30〜40秒（速度×3）動かした。エラーは出なかった。機体と地面の高さの差が、3まで下がった（地面に接した）のは、シード5000、2500、123で、標本の0.1%未満だった。ほかのシードでは、最小でも約7.7あった。シードの欄に、範囲外（-5、99999）、空、数字でない値、小数を入れても、0〜9999の整数に丸められた
- ページを6回開いて、地形のシードが、毎回ランダムに変わる（6回とも違う値、0〜9999の整数）こと、欄の数字と、実際の地形の高さが合うことを確認した。エラーは出なかった
- 自動切り替えの間隔を、0秒、2秒、5秒にして、追っている機体を撃墜扱いにした。切り替えまでの時間は、0.1秒、約2.3秒、約5.6秒だった（ヘッドレスの描画が遅く、1コマの経過時間の上限0.05秒に当たるため、少し長い）。HUDの残りの秒数は、1秒ごとに減った。余韻のあいだに「次の機体」を押すと、すぐ切り替わった。自動切り替えをオフにすると、切り替わらず、「撃墜されました（「次の機体」で切り替え）」のままだった。エラーは出なかった
- 位置取りの有無を比べた（交戦8対8、60秒、速度×3、シード1、機銃オフ。3種類を、機体に均等に割り当てた）。位置取りなしでは、大型は、最短距離より近すぎる時間が約9割で、1秒あたりの発射数が約0.02だった。位置取りありでは、近すぎる時間が約65%に減り、発射数が約0.06〜0.08に増えた（3〜4倍）。熱誘導型は、近すぎる時間が約44%から約17%に、レーダー誘導型は、約70%から約36%に減った。一方、1秒あたりの命中数は、熱誘導型が約0.13から約0.06に、レーダー誘導型が約0.05から約0.03に減った（離れて撃つため、1発あたりの命中率が下がる。大型は、約0.01〜0.02で、ほぼ同じか少し増えた）。エラーは出ず、地面に接した時間は、0.1%未満だった
- 主観視点で、追撃戦・交戦から「主観」を選ぶと、追従カメラが自動でオンになり、視野角が約70度になり、カメラが追っている機体の機首の位置（機体から約3.1）に置かれ、向き（ロールを含む）が機体と一致すること、追っている機体の矢印と地面への線が消え、ほかの機体は残ること、ドラッグで見回すと、離したあと前向きに戻ること、撃墜でカメラが止まること、追従カメラをオフにすると、斜めに戻ること、軌跡だけのモードでは「主観」が出ないことを確認した。エラーは出なかった
- 主観視点の目印: 主観にすると、星空と姿勢表示が出て、チェックボックスも出ること、空を向いたとき（ドラッグで見回した状態）に、星が見えて、水平線の目盛りが、ピッチに合って動くこと、機体をロールさせると、水平線とロールの目盛りが、世界の上下に合わせて傾くこと（地形の側が水平線の下になる）、2つのチェックボックスで、それぞれ消せること、斜めに戻すと、星空・姿勢表示・チェックボックスが消えて、ヒントの文が元に戻ることを確認した。エラーは出なかった
- 交戦4対4（速度×3）で、開始時にエースが各チーム1機（耐久力4の設定で、耐久力6）いて、チーム色の矢印に金色の光輪が付くこと、オフにすると全エースが普通に戻ること、オンにしても「最初から」までは開始時のエースができないことを確認した。交戦8対8の60秒間で、3機を撃墜した機体が昇格し、金色の見た目と耐久力の増加が反映された。追撃戦では攻撃側の1機だけがエース、軌跡だけのモードにはエースがいなかった。エラーは出なかった

**既知の制限**

- 追撃戦と交戦では、機体が地形の範囲（約±160。「戦闘領域の広さ」に合わせて変わる）の外へ出ることがある（時間の数%）。ごく稀に、地面すれすれまで降りる
- 宙返りなどの見せ場の機動は、範囲の中心寄りにいるときだけ始まる。頻度は多くない
- 16対16などでは、ミサイルと軌跡の線が増え、端末によっては重くなる可能性がある
- 両チームが同じ動きをするので、交戦の撃墜数の差は、運の影響が大きい

**保留中の事項**

- チームごとの戦力差（耐久力と攻撃頻度）。「耐久力と攻撃頻度を、チームごとに別々のスライダーで指定する」案を提示した段階で、方式は未決定

**決定の経緯**

| 項目 | 決定内容 |
| --- | --- |
| 軌跡の表現 | 線から、翼幅の帯へ変更。ロールを帯のねじれとして残す。矢印との重なりは、先頭のグラデーションで解消 |
| 追撃戦 | 切り替え式で追加。演出は「派手」（一斉射、フレア、爆発）。標的に回避機動を持たせる |
| ミサイルの種類とチャフ | 熱誘導型（近距離・高機動）とレーダー誘導型（長距離・高速）を追加し、機体ごとに生成時にランダムで固定した。チャフを追加し、誘導方式に合う囮でだけ惑わされるようにした。見た目で違いが出るよう、3種類目として、ほぼ直進して高威力の重爆型を追加したが、扇状に発射して旋回が鈍く、命中率が約3%と低かった。そのため、現実のミサイルに近い大型（2発を連続でまっすぐ発射、高速、素直に追尾、耐久力2減、囮に惑わされない、爆発が大きく、先端が大きな点）に作り直し、「一斉射の数」の設定には従わない2発固定にした。3種類を均等に割り当てる。設定パネルの項目は増やさない |
| ミサイルの当たりすぎ | ミサイルにエネルギーを持たせ、標的のスロットル操作と回避が効くようにした |
| 飛行モデル | 機体座標系の飛行モデルを採用した |
| 耐久力 | 逃げる側だけが被弾し、「耐久力」スライダーを付ける。0で撃墜される |
| 補充 | 範囲の縁から、遠方（約600）からの飛来へ。「補充までの時間」スライダー（初期0秒）を追加し、撃墜された軌跡は別枠で薄れさせる |
| 位置取り | 各機体は、距離に関係なく、標的を追っていた。そのため、大型は、最短距離（80）より近すぎる時間が約9割で、ほとんど撃てなかった。ミサイルの種類ごとの発射距離に合わせた位置取り（撃てる状態、または機銃オフのときは、最短距離より近ければ離れ、遠ければ詰める）を加えた。撃ったあとの待ち時間は、機銃がオンなら近づいて機銃を使う。大型は撃てるようになったが、熱誘導型・レーダー誘導型は、離れて撃つぶん、1発あたりの命中率が下がり、1秒あたりの命中数が減る |
| 自動切り替えの余韻 | 撃墜された瞬間に切り替わると、余韻がなかった。撃墜から次の機体へ切り替えるまでの間隔を、スライダー（0〜5秒、初期2秒）で選べるようにした。0秒で、今までと同じ動きになる。余韻のあいだは、カメラを撃墜された場所で止め、HUDに残りの秒数を出す。操作（「次の機体」、チームの変更）は、待たずに切り替える |
| 追従カメラ | 追撃戦の標的を追うモードから、独立したスイッチへ。撃墜後は停止し、自動切り替えはオプション（初期オフ）。追うチームを選べる |
| 交戦モード | 2チームの対戦。全機が攻撃と回避を行い、撃墜数を右上に表示する |
| 真上カメラ | 「視点」の切り替え（斜め／真上）として追加 |
| 主観視点の目印 | 主観で空を向くと、目印がなく、どう動いているか分からなかった。星空（世界に固定した星）と姿勢表示（水平線、ピッチとロールの目盛り）を、主観のときだけ出し、別々のチェックボックス（初期オン）で、オン・オフできるようにした（1つのチェックボックスにまとめる案、速度・高度・方位の数字、流れる粒は、今回は採用しない） |
| 主観視点 | 追っている機体の機首から見る視点を、「視点」の3つ目（主観）として追加した。選ぶと追従カメラが自動でオンになる（追従カメラがオンのときだけ選べる案、別のチェックボックスにする案は、採用しない）。機体のロールに合わせて画面が傾き、ドラッグで見回せる（水平を保つ案、見回しなしの案は、採用しない） |
| 機銃 | 別の編集で追加された機能。本書の記述は、コードの定数に基づく |
| 地形のシード | 地形の高さ関数を、Inigo Quilez の「morenoise」方式（勾配付きバリューノイズ、quintic補間、オクターブごとに回転、勾配で振幅を抑える）に変えた。設定パネルで、0〜9999の整数のシードを選べる（初期値は、ページを開くたびにランダム。欄に今のシードを表示し、気に入った地形を再現できるようにした）。変えると、描画と物理の高さがすぐ変わり、機体の配置は変わらない。高さ関数は、`terrain.js` に切り出し、プロパティベーステストを付けた。波長・振幅は、以前の地形の高さの分布（平均約12、最大約28）に近づけたが、傾斜は以前（最大約0.9）より急な場所がある（最大約1.8） |
| 戦闘領域の広さ | 戦闘が近距離で起きすぎて、大型の最短発射距離（80）に、約9割の時間で入れなかった。そのため、飛行範囲と地形の広さを、スライダー（×0.5〜×3.0、初期×1.0）で変えられるようにした。動かすと、飛行の限界と地形はすぐ変わり、機体の配置は「最初から」で作り直す（スコアは、リセットしない）。大型の最短距離を下げる案もあったが、全種類の発射機会が増えるこちらにした |
| エース機 | 開始時に、攻撃する側の先頭の1機がエースで、3機の撃墜でも昇格する（数に上限なし）。性能は耐久力1.5倍・旋回10%向上・一斉射+2発で、チーム色の塗りと軌跡のまま、金色の輪郭と金色の光輪、HUDの「ACE」で目立たせる。チェックボックス（初期オン）で選べ、オフにするとすぐ全エースが普通に戻り、オンの開始時エースは「最初から」で作る。追撃戦は攻撃側だけ（逃げる側は攻撃しないので昇格しない）。金色の矢印にすると、交戦のチームBの琥珀色と区別できなかったため、塗りと軌跡はチーム色のままにして、輪郭と光輪でエースを示す |
