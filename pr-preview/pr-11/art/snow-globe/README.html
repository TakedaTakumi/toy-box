スノードーム 仕様書

  • 試作リンク：https://takedatakumi.github.io/toy-box/art/snow-globe/

概要と目的

スマホのジャイロ（傾き）と加速度（振り）を使って、スノードームを再現したものです。傾けると雪が傾いた側へ流れ、振ると雪が舞い上がります。1つのHTMLファイルで動き、ライブラリは使いません。保存されるデータはありません。

ジャイロはHTTPSのページでしか動きません。このリポジトリのGitHub Pagesは、HTTPSで公開されます。

画面構成と操作

画面は、タイトルと状態表示、ドーム、「雪の量」のスライダー、ボタン、ヒントの文で構成します。ドームは、夜空と家と木を入れたガラス球と、台座です。

スマホ

  • 傾けると、雪の落ちる向きが変わる
  • 振ると、雪が舞い上がる。強く振るほど、高く舞う
  • 縦向きと横向きのどちらでも、傾きの向きが合う

PC・ジャイロのない環境

  • ドームをドラッグすると、ドラッグの向きと速さに応じて雪が動く。素早く動かすほど、雪が舞い上がる
  • 「ふる」ボタン、またはスペースキーで、振った扱いになる

ジャイロの仕様

傾きは deviceorientation、振りは devicemotion から読みます。

傾き（重力の向き）

  • beta（前後の傾き）と gamma（左右の傾き）から、画面上の重力の向きを求める。画面の向き（0・90・180・270度）に合わせて回す
  • 端末を水平に置いたときも、わずかに下向きの重力を足して、雪が完全には止まらないようにする
  • 向きの変化はなめらかにならして使う

振り

  • 重力を除いた加速度の大きさが7m/s²を超えると、振ったとみなす。重力を除いた値が取れない端末では、重力を含む加速度の大きさの変化量で代用する
  • 強さは、超えた分に応じて決める（上限あり）。連続して反応しないよう、60ミリ秒は間を空ける

雪の挙動

雪の粒を、ドームの中の2次元の粒子として動かします。

  • 粒の数は、「雪の量」のスライダーで50〜600に変えられる（初期は240）。「視差効果を減らす」設定では、初期が110で、上限が300。大きさは粒ごとに違う
  • 数を増やすと、増えた分の雪が、ドームの上のほうから降り始める。減らすと、その分の雪が消える
  • 重力と空気抵抗でゆっくり落ちる。小さい粒ほど軽く、遅く落ちる（終端速度は約36〜55）
  • 粒ごとに違う周期で、横と縦にゆれながら漂う
  • 振ると、粒ごとに「かくはん度」が上がり、約2〜4.5秒かけて0に戻る。かくはん中は、重力と空気抵抗が弱まり、ゆれが強まるので、舞い上げた雪がしばらく漂う
  • ガラスの内側と、ドームの底（家が立つ雪の地面）で止まる。積もった雪が1点に固まらないよう、粒ごとに積もる高さを変える
  • OSの「視差効果を減らす」設定では、粒の数・重力・ゆれを減らす

見た目

  • ドームの中は、夜空・月・家・木3本・雪の地面。家の窓は明かりが点いている
  • 台座は、金色の縁のある木製
  • ページの背景と文字は、ライト・ダークに合わせて切り替わる。ドームの中は、どちらでも夜の景色

検証状況・制限・保留事項

検証した内容

  • ヘッドレスのブラウザで、表示・コンソールにエラーが出ないこと・傾きのイベントを入れたときの状態表示の切り替え・振りのイベントで雪が舞うことを確認した

確認できていないこと

  • 実機のスマホでの傾きと振りの感触。ヘッドレスのブラウザは、センサーを持たないので、疑似のイベントで確かめた
  • iPhoneでの許可ダイアログの表示

既知の制限

  • ジャイロは、HTTPSのページでしか動かない。ファイルを直接開く（file://）と、動かないことがある
  • アプリ内のブラウザやアーティファクトの表示領域では、センサーの値が届かないことがある。その場合はドラッグで操作する
  • ドームの中の景色は、画面に固定している。端末を傾けても、ドームの絵は傾かず、雪の向きだけが変わる
