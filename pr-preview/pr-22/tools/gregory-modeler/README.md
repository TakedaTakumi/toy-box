# グレゴリー曲面モデラ（Rust 版）

[グレゴリーメッシュエディタ試作](../gregory-mesh-editor/)（JavaScript）の曲面の数学を Rust に移した `gregory-core` を使い、**ケージから組み立てたグレゴリー曲面を GPU で描く**ブラウザアプリです。この段階では表示と表示の設定だけを扱い、頂点の選択・移動・押し出しなどの編集はまだできません。

- 成果物：WebAssembly（Rust + egui + wgpu）。WebGPU に対応したブラウザでは WebGPU、そうでなければ WebGL2 で描く
- デスクトップ版：`cargo run -p gregory-editor` でも同じ画面が開く

## 何を確かめるための段階か

| 問い | この段階での見せ方 |
| --- | --- |
| `gregory-core` の出力を、そのまま GPU で描けるか | プリセットのケージから曲面を組み立て、深度バッファ付きで描く |
| egui の画面構成で、JS 試作と同じ情報を出せるか | 左にツール、右に連続性の検証、下に頂点数や UI 処理の CPU 時間（前フレーム分。GPU 時間は含まない）を出す |
| WebGPU と WebGL2 の両方で同じ見た目になるか | 使っているバックエンドをステータスバーに出す |

## 使い方

1. 左のツールパネルの「形状」で、立方体・平面・四角錐・三角柱から選ぶ
2. 「表示」で、スムース／フラット、曲面とケージの表示、分割数を切り替える
3. 3D ビューをドラッグして回し、ホイール（またはピンチ）で拡大縮小する
4. 右のプロパティパネルで、G0・G1 の検証結果と形の数を確かめる

### 操作

| 操作 | 内容 |
| --- | --- |
| ドラッグ | 視点を原点のまわりに回す（上下は ±約 83° まで） |
| ホイール / ピンチ | 拡大縮小（カメラの距離 3〜16） |
| ダブルクリック | 視点を初期位置に戻す（「視点をリセット」ボタン・「表示」メニューと同じ） |
| `S` | スムースとフラットの切り替え |
| 「表示」メニュー | 左右のパネルの開閉、表示の切り替え |

## 機能仕様

| 項目 | 内容 |
| --- | --- |
| プリセット | `gregory-core` の `PRESETS`（立方体・平面・四角錐・三角柱）。ハンドル長は 1、接線場は G1 |
| 分割数 | 4〜16（初期値 8）。範囲外の値は範囲に丸める |
| スムース | `gregory-core` の頂点法線をピクセルごとに補間して光を当てる |
| フラット | 細かい三角形ごとに頂点を分け、三角形の面法線で光を当てる |
| 光の当て方 | JS 試作と同じ（カメラから見て左上手前の平行光、環境光、弱いハイライト）。裏面も表と同じように照らす |
| ケージ | 辺を線、頂点を小さな四角で描く。折れ目の辺は橙色。線と点は常に曲面の手前に重ねて描く |
| 連続性の検証 | G0 は共有辺の位置の最大の隙間、G1 は滑らかな共有辺の法線の最大差（度）。0.5° 未満を「G1 成立」とする（JS 試作と同じ） |
| 再計算 | プリセットか分割数が変わったときだけ曲面を組み立て直す。シェーディングの切り替えでは GPU に送る配列だけを作り直す |

## 既知の制約

- 編集（選択、移動、押し出し、ループ分割、折れ目、ミラー、元に戻す）はまだない
- ハンドル長は 1 で固定。ベジェ曲線と制御点、座標軸、移動ハンドルは描かない
- ケージの線と点は常に曲面の手前に重ねて描き、裏向きの頂点・辺を隠す処理は未対応
- 線は 1 ピクセルの太さで、アンチエイリアスはかけない（MSAA を使わないため、曲面の輪郭もギザギザが出る）
- 表示の設定は保存しない（ページを開き直すと初期状態に戻る）
- WebGPU と WebGL2 のどちらにも対応していないブラウザでは、起動時に失敗した旨を表示して止まる。起動後に Rust 側で panic したときは、再読み込みを促す表示を出す。wasm の取得・初期化そのものに失敗した場合は、20 秒たっても読み込み中の表示が消えなければ、失敗した可能性を案内する

## 実装メモ

| 項目 | 内容 |
| --- | --- |
| 構成 | Rust + egui 0.37（eframe）+ wgpu 30。曲面の数学は `crates/gregory-core` |
| 描画 | egui の paint callback（`egui_wgpu::Callback`）の中で、自前の WGSL のパイプラインで描く。深度バッファは 24 ビット（`Depth24Plus`）、MSAA なし |
| 座標系 | 右手系の Y-up。カメラの初期値と焦点距離（ビューの短い辺 × 1.55）は JS 試作と同じ |
| 画面 | egui 標準のダークテーマ。上にメニューバー、左にツール、中央に 3D ビュー、右にプロパティ、下にステータスバー。狭い画面では左右のパネルを閉じて始める |
| フォント | HackGen を改変した Gregory UI Sans（SIL Open Font License 1.1）。UI で使う文字だけに絞っている |
| ビルド | `crates/gregory-editor` で `trunk build --release`。出力先は `public/tools/gregory-modeler/`（生成物のため Git では追跡しない） |

## ファイル構成

```
crates/gregory-editor/
├─ Cargo.toml
├─ Trunk.toml           # trunk の設定（出力先など）
├─ index.html           # trunk の入力（canvas と読み込み中の表示）
├─ README.md            # このページ
├─ assets/fonts/        # UI のフォントとライセンス（LICENSE 類は fonts/ に公開する）
└─ src/
   ├─ main.rs           # ネイティブと web の起動
   ├─ lib.rs
   ├─ app.rs            # アプリの状態と 1 フレームの処理
   ├─ settings.rs       # 表示の設定
   ├─ scene.rs          # プリセットから曲面を組み立てる
   ├─ memo.rs           # 入力が変わったときだけ計算し直す入れ物
   ├─ mesh_buffers.rs   # GPU に送る頂点・インデックス・線分・点の配列
   ├─ camera.rs         # オービットカメラと変換行列
   ├─ readouts.rs       # 検証結果・数・バックエンド名の表示用の値
   ├─ palette.rs        # 3D ビューの色
   ├─ fonts.rs          # フォントの登録
   ├─ panels/           # メニューバー・ツール・プロパティ・ステータスバー
   └─ viewport/         # 3D ビューの入力、wgpu の資源、WGSL シェーダ
```
