# すうじタワー

計算ミスをした時点で終わる、タワー登りの計算ゲームのプロトタイプです。
正解するたびに塔を1階ずつ登り、まちがえる（または時間切れになる）と終了して、何階まで登れたかを表示します。

- 形式: 単一の HTML ファイル（ビルド不要）
- 操作: テンキー（画面のキー、またはキーボードの数字・Backspace・Enter）
- 状態: プロトタイプ（Claude で作成。Playwright での動作確認は実施済み。実機での検証は未実施）
- 元になったゲーム: すうじモンスター。選択肢を適当に選んで進める遊び方を防ぎ、計算ミスを減らす練習にするために作った

## 遊び方

1. ホームで「じかん」「やすみ」「たかさ」を選び、「のぼる！」を押す
2. 吹き出しに式が出る（例: `？ ＋ 5 ＝ 8`）
3. テンキーで？に入る数を入れて「OK」を押す
4. 正解すると塔に1階分のブロックが積まれ、次の問題へ進む
5. まちがえる、または時間切れになると終了。何階まで登れたかが出る

## 出題仕様

すうじモンスターの「ごちゃまぜ × むずかしい」と同じ。

- たしざん: 一桁どうし（1〜9）。答えは最大 18
- ひきざん: 引かれる数 2〜9、引く数 1〜引かれる数。答えは 0 以上（0 になる式も出す）
- 穴の位置は、左または真ん中の数（`？ ＋ 5 ＝ 8` / `3 ＋ ？ ＝ 8` / `？ － 3 ＝ 5` / `8 － ？ ＝ 3`）。答えの数（右辺）が穴になる式は出さない
- 全 250 問をシャッフルして出す。1周のあいだ同じ問題は出ない。`3 ＋ 5` と `5 ＋ 3`、穴の位置が違う式は別の問題として数える

## 設定（ホーム）

| 項目 | 選択肢 | 初期値 |
|---|---|---|
| じかん（1問の制限時間） | 5 / 10 / 15 / 20 秒 / なし | 10 秒 |
| やすみ（休憩を入れる間隔） | 25 問ごと / 50 問ごと | 25 問ごと |
| たかさ | ちょうじょうまで / むげん | ちょうじょうまで |

選んだ設定はページを開いている間だけ覚える（保存しない）。

## 終了条件

| 終了 | 条件 |
|---|---|
| まちがい | OK を押した答えが違う。やり直しはできず、その場で終了。正しい答えを見せてから結果画面へ進む |
| 時間切れ | 制限時間が 0 になったら、まちがいと同じく終了する（「なし」を選んだときは起きない） |
| 頂上クリア | 「ちょうじょうまで」で 250 問すべて正解したとき |
| ここでおわる | 休憩画面で「ここで おわる」を選んだとき。それまでの階数が記録になる |

「むげん」では 250 問を出し切ったら、もう一度シャッフルして続ける。このとき同じ問題が再び出るので、答えを覚えていると有利になる。周回の切れ目で同じ問題が2回続くことはない。

## 制限時間

- 吹き出しの上のゲージで残り時間を見せる。残り 3 秒でオレンジになる
- 別のタブを見ている間は進まない（1フレームで進める時間を 100ms までにしている）
- 正解の演出中と休憩中は止まる
- 「動きを減らす」設定の端末では、ゲージを1秒ごとの段階表示にする

## 休憩

- 正解の階数が 25（または 50）の倍数になったとき、休憩画面を出す
- 休憩中はタイマーを止める。「つづける」で次の問題へ、「ここで おわる」で結果へ進む
- 頂上（250 階）に着いたときは休憩ではなくクリアにする

## 入力（テンキー）

- 入力した数字は、吹き出しの穴（？の位置）に出る。最大 2 桁
- 先頭が 0 のときに別の数字を押すと、0 を置き換える（`05` にならない）
- 「OK」は入力があるときだけ押せる
- 「けす」で 1 文字消す
- 数字以外のキー入力は無視する

## 結果画面

- 登れた階数（= 正解した数）と、終了の理由を出す
- まちがい・時間切れのときは、その式と正しい答えを出す
- ベスト: 同じ設定（じかん・たかさ）での最高階数。ページを開いている間だけ覚える。更新したときは「ベストこうしん！」と出る
- 休憩の間隔は、ベストの比較条件に含めない

## 保存するデータ

ブラウザの `localStorage` に保存するのは、次の1つだけ。

| キー | 内容 |
|---|---|
| `st_sound` | 効果音のオン/オフ |

設定、ベスト、成績は保存しない。保存に失敗しても（プライベートブラウズなど）、そのまま遊べる。

## 技術メモ

- 単一の HTML ファイル（HTML / CSS / JavaScript をすべて同梱）。フレームワーク・ビルド不要
- 外部リソース: Google Fonts（M PLUS Rounded 1c）のみ。読み込めない場合は端末の丸ゴシック系フォントで表示する
- 画像ファイルなし。モンスターは SVG、効果音は Web Audio API で生成している
- 画面には直近 5 階分のブロックだけを積んで見せる（それ以前の階は下に隠れる）
- ダークモード、「動きを減らす」設定、スマホのセーフエリアに対応
- 動作確認（Playwright・時計を進めて確認）: 正解の連続、まちがい終了、時間切れ終了、「なし」で時間切れしないこと、25・50 問での休憩と休憩中のタイマー停止、250 問の重複なし・頂上クリア、「むげん」で 260 階まで継続、テンキーの入力規則（先頭 0・2 桁・空 OK）
